# ماسح المستندات — DocScanner OCR 2.0

تطبيق أندرويد مكتوب بالكامل بلغة **Kotlin** (واجهة Jetpack Compose) لتصوير الأوراق
واستخراج النصوص والأرقام **كما هي وبنفس ترتيبها**، مع **عرض الصورة والنص في الوقت نفسه**،
ونص كبير قابل للتحرير، وأرقام قابلة للضغط لنسخها فوراً.

التعرف على النصوص يتم **داخل الجهاز** (بدون إنترنت) باستخدام **Google ML Kit Text
Recognition v2** بنموذج Latin المضمّن داخل التطبيق. يقرأ التطبيق النصوص الإنجليزية
والأرقام اللاتينية بدقة عالية، ولا يدعم الخط العربي.

---

## الجديد في الإصدار 2.0

- **Google ML Kit فقط**: محرك واحد سريع ودقيق، بدون Tesseract أو ملفات نماذج خارجية.
- **مستندات متعددة الصفحات**: التقط عدة صفحات في جلسة واحدة، أضف صفحات لمستند موجود،
  أو استورد عدة صور من الجهاز دفعة واحدة.
- **الصورة والنص معاً**: شاشة النتيجة تعرض معاينة الصفحة أعلى الشاشة (أو بجانب النص
  على الأجهزة العريضة) بينما تحتل مساحة النص معظم الشاشة.
- **نص كبير + نسخ بضغطة**: كل رقم داخل النص ملوّن وقابل للضغط لنسخه مباشرة، مع زر
  «نسخ كل النص» ووضع تحرير كامل.
- **ترتيب مطابق للصورة**: ترتيب الأسطر من أعلى إلى أسفل ثم من اليسار إلى اليمين.
- **اختصار كاميرا سريع**: أيقونة كاميرا على شاشة الهاتف الرئيسية (App Shortcut) تفتح
  الكاميرا مباشرة، إضافة إلى بطاقة الكاميرا الكبيرة أعلى الصفحة الرئيسية.
- **أحدث المستندات بدون نص**: كل مستند حديث يظهر بصورته، وتحتها **أرقامه فقط** بترتيب
  ظهورها في المستند؛ اضغط أي رقم لنسخه، واضغط المستند لعرض النص الكامل.
- **عدسة بحث فورية**: اكتب جزءاً من رقم (مثل `128` أو `1283773`) فتظهر فوراً صور
  الصفحات التي تحتوي عليه، مع أرقامها المطابقة فقط.
- **نسخ مع عدّاد ونجمة**: بعد كل نسخ تظهر رسالة «تم نسخ الرقم بنجاح» مع عدد مرات النسخ،
  وتظهر نجمة ⭐ وعدد النسخ على صورة المستند.
- **دقة أعلى**: تصحيح ميل الصفحة تلقائياً (Deskew)، معالجة تكيّفية للصورة، وتكبير
  الصور الصغيرة قبل التعرف.
- **إعادة تعرف** لأي صفحة بضغطة واحدة بعد تدويرها أو تغيير المعالجة.
- **تصدير PDF متعدد الصفحات** (A4) و**TXT**، ومشاركة النص أو صورة الصفحة.
- **سجل احترافي**: بحث، ترتيب (الأحدث/الأقدم/الاسم)، تحديد متعدد، حذف مع **تراجع فوري**،
  وسلة محذوفات تُفرّغ تلقائياً بعد 7 أيام.
- **إعدادات مبسّطة**: المظهر (نظام/فاتح/داكن) والوضع **الفاتح هو الافتراضي**، المعالجة،
  تصحيح الميل، وإظهار مواضع النص.

## المزايا الأساسية

- **تصوير مباشر** بكاميرا داخل التطبيق (CameraX) مع فلاش وتبديل الكاميرا، أو اختيار صور.
- **استخراج النصوص بالترتيب**: الحفاظ على تخطيط الصفحة وترتيب القراءة من أعلى لأسفل.
- **استخراج الأرقام كما هي**: أرقام لاتينية (123) مع الفواصل العشرية/الآلاف والتواريخ
  والنسب المئوية، وبالترتيب حسب ظهورها، بما في ذلك الأرقام الطويلة المفصولة بمسافات.
- **أرقام جاهزة للنسخ**: تظهر أرقام أحدث المستندات في الصفحة الرئيسية مباشرة، وكل رقم
  في سطر مستقل قابل للضغط لنسخه، مع عدّاد ونجمة على الصورة.
- **بحث بالرقم عبر الصور**: اكتب رقماً أو جزءاً منه في عدسة البحث أعلى الرئيسية لتظهر
  الصفحات المطابقة بصورها وأرقامها فوراً.
- **مصمّم للمكتبات الكبيرة**: قوائم Lazy، صور مصغّرة مخزّنة بذاكرة محدودة، فهرس خفيف،
  ومعالجة OCR صفحة بصفحة دون تحميل كل الصور في الذاكرة.
- **معاينة تفاعلية**: تكبير الصورة بإصبعين، وإطارات ملوّنة حول كل سطر.
- **نسخ من كل مكان**: الضغط على أي رقم لنسخه، أو نسخ كل النص، أو تحرير النص أولاً.
- **واجهة عربية RTL** مع واجهة إنجليزية حسب لغة الجهاز، ووضع داكن اختياري
  (الوضع الفاتح افتراضي).
- **كل البيانات محلية** داخل مساحة التطبيق الخاصة، دون أي إذن تخزين أو اتصال بالإنترنت.

## التخزين المحلي

```
filesDir/documents/
├── index.json                 فهرس خفيف للسجل (أرقام وصور مصغّرة لكل صفحة للبحث)
├── docs/<id>.json             المستند الكامل: الصفحات + الأسطر + الأرقام
├── images/<docId>_<pageId>.jpg
├── thumbs/<docId>_<pageId>.jpg
└── trash/<id>.json            محذوفات مؤقتة (7 أيام للتراجع)
cacheDir/pending/<session>/    الصفحات الملتقطة قبل إنهاء المستند
```

- الكتابة **ذرّية** (ملف مؤقت ثم إعادة تسمية) لمنع تلف البيانات.
- تُنقل الصفحات من الكاش إلى مجلد المستند عند الحفظ، وتُحذف الملفات اليتيمة عند التشغيل.
- **ترحيل تلقائي** لبيانات الإصدار 1 (`filesDir/scans`) عند أول تشغيل بعد التحديث.

## طريقة العمل

1. اضغط **تصوير مستند** (أو أيقونة الكاميرا على شاشة الهاتف) والتقط عدة صفحات، ثم **إنهاء**.
   كل صفحة تُحفظ فوراً حتى لا يتأخر التطبيق مع الصفحات الكثيرة.
2. يعالج التطبيق كل صفحة: فك الترميز، تصحيح الميل إن لزم، ثم معالجة الصورة
   (تلقائية/رمادية/أبيض وأسود/ملونة) وتشغيل ML Kit محلياً.
3. في الصفحة الرئيسية تظهر صورة كل مستند حديث وتحتها أرقامه فقط بترتيبها.
   **اضغط أي رقم لنسخه**؛ ستظهر رسالة بعدد مرات النسخ ونجمة على صورة المستند، أو اضغط
   المستند لفتح النتيجة: الصورة أعلى الشاشة مع إطارات الأسطر، والنص الكامل في مساحة
   كبيرة مع تمييز الأرقام.
4. اكتب رقماً في **عدسة البحث** أعلى الرئيسية (مثل `1283773` أو أول رقمين منه) لتظهر
   فوراً صورة الصفحة التي تحتوي عليه مع الأرقام المطابقة.
5. زر **تحرير النص** يفتح حقل نص كامل لتعديل النص قبل النسخ أو المشاركة.
5. يمكنك إعادة التسمية، إضافة صفحات أو صور، تدوير صفحة، إعادة التعرف، حذف صفحة،
   تصدير PDF/TXT، أو المشاركة. كل ذلك محفوظ في السجل.

## الدقة

- **نموذج ML Kit مضمّن**: يعمل دون إنترنت بعد تثبيت التطبيق، ويقرأ الإنجليزية والأرقام
  اللاتينية بدقة عالية حتى في الصور المتوسطة.
- **تصحيح الميل**: قياس زاوية الميل وتدوير الصفحة قبل التعرف.
- **المعالجة التكيّفية**: عتبة محلية عبر الصورة التكاملية لمعالجة الظلال والإضاءة
  غير المتساوية، مع تحويل تلقائي إلى تدرج رمادي لأن التمييز الحاد قد يحذف الأرقام الرقيقة.
- **تكبير الصور الصغيرة**: رفع الحد الأدنى لأبعاد الصورة قبل التعرف لتحسين الأرقام الصغيرة.
- **ترتيب مضمون**: فرز الكتل والأسطر حسب الموضع (أعلى ← أسفل، يسار ← يمين) ليطابق النص
  ترتيب الصورة.

> للحصول على أفضل نتيجة: صوّر الورقة كاملة على سطح مستوٍ وبإضاءة جيدة، وثبّت الهاتف.

## البناء والتشغيل

### المتطلبات

- Android Studio **Koala (2024.1.1)** أو أحدث، أو سطر الأوامر مع:
  - JDK 17
  - Android SDK Platform 34 + Build-Tools 34
- اتصال إنترنت أثناء أول بناء فقط (لتحميل التبعيات).

### من Android Studio

1. افتح المجلد `DocScannerOCR` كمشروع Gradle.
2. انتظر مزامنة Gradle (سيُنزّل Google ML Kit من مستودع Google).
3. اضغط **Run ▶**.

### من سطر الأوامر

```bash
# ملف local.properties يحتاج مسار الـ SDK (Android Studio ينشئه تلقائياً)
echo "sdk.dir=/path/to/Android/Sdk" > local.properties

./gradlew assembleDebug
# الناتج: app/build/outputs/apk/debug/app-debug.apk

# أو لتثبيت مباشر على جهاز/محاكي موصول:
./gradlew installDebug
```

### الحد الأدنى للإصدار

`minSdk = 26` (أندرويد 8.0) و `targetSdk = 34`، والإصدار الحالي `versionName = "2.0.0"`.

## محرك التعرف (ML Kit)

- الاعتمادية: `com.google.mlkit:text-recognition:16.0.1`.
- النموذج **مضمّن في APK** (Bundled)، لذلك لا يحتاج التطبيق إلى تنزيل نموذج بعد التثبيت
  ولا إلى اتصال بالإنترنت.
- يدعم **الخط اللاتيني والأرقام اللاتينية** فقط. النصوص العربية غير مدعومة بواسطة هذا
  النموذج، ولذلك أُزيل خيار اللغة العربية وTesseract.
- حجم APK أكبر (~59MB) بسبب تضمين النموذج، مقابل دقة أعلى واستقلال كامل عن الشبكة.

## أفكار للتطوير (اختيارية)

- قص حدود الورقة تلقائياً (Edge Detection) قبل التصحيح.
- البحث داخل النص الكامل وإبراز نتائج البحث على الصورة.
- تصدير الأرقام إلى CSV مع الاحتفاظ بترتيبها.
- مزامنة/نسخ احتياطي اختياري للمستندات.

## الترخيص وإخلاء المسؤولية

- المشروع مكتوب خصيصاً لك، ويمكنك تعديله واستخدامه بحرية.
