الحالة: تم تعديل الكود فقط. لم يُنفَّذ بناء (لا يوجد JDK / Android SDK في البيئة)، ولم تتم أي مزامنة إلى GitHub.

======================================================================
1) القرار المعماري
======================================================================
- اعتُمد المحرك الهجين (Hybrid):
  * ML Kit Text Recognition v2 (نموذج Latin مدمج داخل APK) → الإنجليزية والأرقام.
  * Tesseract (ara / ara+eng) → العربية، لأنه لا يوجد نموذج عربي يعمل دون إنترنت في ML Kit.
  * عند اختيار «العربية + الإنجليزية» يعمل المحركان معاً وتُدمج النتائج.
- سبب الإبقاء على Tesseract: ML Kit on-device يدعم Latin/Chinese/Devanagari/Japanese/Korean فقط، ولا يدعم العربية. حذف Tesseract كان سيُفقد استخراج العربية نهائياً.
- كل التعرف ما زال داخل الجهاز ودون إنترنت. ML Kit هنا بنسخة bundled، أي أن النموذج داخل التطبيق ولا يحتاج تنزيلاً.

2) الملفات المعدّلة / المضافة
======================================================================
- app/build.gradle.kts
  * إضافة: implementation("com.google.mlkit:text-recognition:16.0.1")
  * الإبقاء على Tesseract4Android 4.9.0.

- app/src/main/java/com/docscanner/ocr/ocr/MlKitOcrEngine.kt  (جديد)
  * محرك ML Kit: TextRecognition + InputImage.fromBitmap.
  * يحوّل TextBlock/Line إلى OcrLine مع الإحداثيات.
  * يحسب الأرقام عبر NumberExtractor.
  * لا يعتمد على أي تنزيل خارجي (bundled).

- app/src/main/java/com/docscanner/ocr/ocr/HybridOcrEngine.kt  (جديد)
  * توجيه حسب اللغة:
      ENGLISH        → ML Kit
      ARABIC         → Tesseract
      ARABIC_ENGLISH → Tesseract + ML Kit ثم دمج
  * الدمج:
      - الأسطر العربية تبقى من Tesseract.
      - الأسطر اللاتينية/الرقمية تُستبدل بنتيجة ML Kit عند تداخل الإحداثيات (IoU).
      - تُضاف أسطر ML Kit غير المتداخلة فقط إذا احتوت رقماً (لاستعادة الأرقام التي فاتت Tesseract).
      - ترتيب نهائي حسب top ثم left، مع إزالة التكرار.
  * المحركان يتلقيان نفس الصورة المعالجة، لذلك الإحداثيات قابلة للمقارنة.

- app/src/main/java/com/docscanner/ocr/MainViewModel.kt
  * استخدام HybridOcrEngine بدل TesseractOcrEngine.
  * الإنجليزية + وضع AUTO → GRAYSCALE (تجنب الثنائية العدوانية التي تمحو الأرقام).
  * فلتر الثقة لا يحذف أي سطر يحتوي رقماً إطلاقاً.
  * «إعادة التعرف» تستخدم AUTO بدل فرض BINARIZED.

- app/src/main/java/com/docscanner/ocr/ocr/NumberExtractor.kt

  * يحافظ على 0-9 و٠-٩ و۰-۹ والفواصل والنسبة المئوية.

- app/src/main/java/com/docscanner/ocr/util/ImageUtils.kt

  * إضافة ensureMinSize: تكبير الصور الصغيرة حتى 1400px (بحد أقصى 2x).
  * isLowContrast: العتبة 900 → 500 (ثنائية أقل عدوانية).
  * binarize: نصف قطر أكبر (min/20) وعتبة ألطف (لا تقل عن 8) للحفاظ على الخطوط الرقيقة.
  * إضافة cropCenterJpeg لقص منتصف صورة الالتقاط في وضع البطاقة الصغيرة.

- app/src/main/java/com/docscanner/ocr/ui/CameraScreen.kt

  * تركيز باللمس (tap-to-focus + AE) عبر FocusMeteringAction.

  * إبقاء المعاينة مع إظهار مواضع النص، والتصدير/المشاركة/إضافة الصفحات/الحذف.

3) تحسينات دقة الاستخراج (ما الذي يعالج مشكلة الأرقام)
======================================================================
1. جودة الالتقاط: أقصى جودة بدل أقصى سرعة.
2. تركيز حقيقي باللمس قبل الالتقاط.
3. وضع البطاقة: تقريب + إطار + قص مركزي، فتصبح الأرقام أكبر في الصورة النهائية.
4. ML Kit كمسار ثانٍ يلتقط الأرقام اللاتينية التي قد يفوتها Tesseract.
5. عدم حذف سطر يحوي رقماً بسبب الثقة المنخفضة.
6. دعم الأرقام المفصولة بمسافات.
7. معالجة صور أخف (ثنائية أقل) وتكبير الصور الصغيرة.
8. تصحيح ميل الصفحة ما زال يعمل كما هو.

======================================================================
4) ما لم يتم التحقق منه
======================================================================
- لم يُنفَّذ ./gradlew assembleDebug لأن البيئة لا تحتوي JDK ولا Android SDK.
- لم تُجرَّب الواجهة على جهاز/محاكي.
- لم تتم مزامنة GitHub ولم يُبنَ APK عبر Actions (بانتظار أمر صريح).
- يجب التحقق عند أول بناء من:
  * توافق إصدار ML Kit 16.0.1 مع compileSdk 34 (متوقع: يعمل).
  * استيرادات ML Kit: com.google.mlkit.vision.text.latin.TextRecognizerOptions.
  * عمل الكاميرا/التركيز/التقريب على الجهاز.
  * زمن المعالجة في وضع AR+EN (يعمل محركان، لذلك قد يكون أبطأ).

======================================================================
5) كيف تختبر المشكلة الأصلية
======================================================================
1. صوّر ورقة/بطاقة واي فاي تحتوي أرقاماً لاتينية.
2. اختر لغة «الإنجليزية» للحصول على مسار ML Kit مباشرة (الأدق للأرقام).
3. أو اختر «العربية + الإنجليزية» لاختبار الدمج.
4. جرّب وضع البطاقة الصغيرة (أيقونة البطاقة) من مسافة قريبة.
5. تأكد أن الأرقام تظهر في الحقل الواحد، وأن ترتيب الأسطر لم يتكرر أو يُحذف.

ملاحظة مهمة
======================================================================

إن أردت لاحقاً حذف Tesseract نهائياً فسيجب القبول بفقدان OCR العربي، أو استخدام خدمة سحابية (تتطلب إنترنت).
